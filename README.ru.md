# Transmitter

![Снимок экрана Transmitter](screenshot.png)
![Детали торрента](screenshot2.png)

Transmitter — современная и лёгкая альтернатива стандартному веб-интерфейсу Transmission. Работает без внешних зависимостей. Также поддерживает интеграцию с Telegram-ботом.

## Возможности

- **Базовые операции** — сортируемый список (имя, статус, прогресс, размер, скорость, дата добавления, ETA) с фильтрами по статусу, поиском по имени без учёта регистра, добавлением по магнет-ссылке или .torrent-файлом и паузой/возобновлением/удалением
- **Заметки** — произвольный текст для любой раздачи (хранится на сервере в SQLite, виден в списке, панели деталей и Telegram-боте)
- **Ночная смена** — отметьте торренты кнопкой с луной, чтобы они качались и раздавались только в заданном окне; вне окна они приостанавливаются
- **Дневная смена** — то же самое, но со своей меткой, своим окном и кнопкой с солнцем; смены независимы, торрент можно отметить для обеих
- **Переключатели смен** — любую настроенную смену можно выключить в «Настройки → Смены»; состояние хранится на сервере в SQLite, поэтому действует во всех браузерах и сохраняется после перезапуска. Пока смена выключена, её планировщик ничего не делает: торренты остаются в текущем состоянии, а кнопка смены становится серой
- **Impact** — сколько раздача вернула от того, что скачала. Кубок отмечает те, что отдали 100% от закачки, фильтр «Недоотданные» показывает остальные (их можно разом отправить в смену), а отдельный переключатель снимает её с раздачи по достижении цели
- **Глобальная пауза** — кнопка в шапке ставит на паузу все работающие раздачи и запоминает, какие именно; при снятии паузы запускаются только они, а остановленные вами вручную остаются остановленными. Состояние хранится на сервере и переживает перезапуск; пока пауза включена, смены ничего не трогают
- **Заметки** — свободный текст в начале главного экрана (по умолчанию 3 строки, растёт вместе с текстом), автоматически сохраняется в SQLite
- **Офлайн-режим** — без соединения интерфейс всё равно открывается и показывает раздачи, заметки и настройки на момент последней синхронизации, о чём сообщает баннер; действия, требующие сервера, недоступны до восстановления связи. Чтобы сама страница открывалась без сети, нужен HTTPS или localhost (service worker)
- **Поддержка локалей**: en, ru, es, de
- **Docker images**: linux/amd64, linux/arm/v7, linux/arm64/v8

## Начало работы

```bash
cp .env.example .env

# отредактируйте .env под свои нужды

docker-compose up -d
```

Откройте браузер: `http://localhost:8080`

### Конфигурация

Все настройки задаются через переменные окружения:

| Переменная | Обязательна | По умолчанию |
|-----------|-------------|--------------|
| `TRANSMISSION_USER` | Да | — |
| `TRANSMISSION_PASS` | Да | — |
| `TRANSMISSION_URL` | Нет | `http://localhost:9091/transmission/rpc` |
| `LISTEN_ADDR` | Нет | `127.0.0.1:8080` (в Docker-образе: `0.0.0.0:8080`) |
| `CORS_ORIGIN` | Нет | `http://localhost:8080` |
| `WEBUI_ENABLED` | Нет | `true` |
| `TELEGRAM_BOT_ENABLED` | Нет | `false` |
| `TELEGRAM_TOKEN` | При использовании бота | — |
| `TELEGRAM_USERS` | При использовании бота | — |
| `LOG_LEVEL` | Нет | `info` |
| `FILE_PRIORITY_ENABLED` | Нет | `false` |
| `FILE_PRIORITY_HIGH_COUNT` | Нет | `3` |
| `NIGHT_SHIFT_START` | Нет | — (отключено) |
| `NIGHT_SHIFT_END` | Нет | — (отключено) |
| `NIGHT_SHIFT_INTERVAL` | Нет | `1m` |
| `DAY_SHIFT_START` | Нет | — (отключено) |
| `DAY_SHIFT_END` | Нет | — (отключено) |
| `DAY_SHIFT_INTERVAL` | Нет | `1m` |
| `DB_PATH` | Нет | `data/transmitter.db` (в Docker-образе: `/app/data/transmitter.db`) |
| `TORRENT_NOTE_MAX_LENGTH` | Нет | `200` |
| `TORRENT_NOTE_CLEANUP_INTERVAL` | Нет | `1h` |
| `IMPACT_TARGET_RATIO` | Нет | `1` |
| `IMPACT_INTERVAL` | Нет | `5m` |
| `SENTRY_DSN` | Нет | — (отключено) |
| `SENTRY_ENVIRONMENT` | При использовании Sentry | — |

Все параметры см. в [.env.example](.env.example).
